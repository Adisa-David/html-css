# thoughtbot Blog — HTML & CSS Recreation

A front-end recreation of the [thoughtbot blog](https://thoughtbot.com/blog) built with plain HTML and CSS.

## Live Site
[https://adisa-david.github.io/html-css/](https://adisa-david.github.io/html-css/)

## What's Included
- Fixed navigation header with dropdown menus
- Blog post listing with authors, dates, and topic tags
- Email subscription form
- Paginated post navigation
- Footer with links and trademark section
- Responsive layout for smaller screens

## Built With
- HTML5
- CSS3 (Flexbox, media queries)

## How to Run Locally
Clone the repo and open `index.html` in your browser — no setup needed.

```bash
git clone https://github.com/Adisa-David/html-css.git
```
